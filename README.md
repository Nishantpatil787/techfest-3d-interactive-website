# NEXUS-7 — Techfest Interactive Website

A futuristic, interactive landing page created for the **Techfest 3D Interactive Website** challenge.

NEXUS-7 presents a fictional cybernetic neural-interface platform through a modern sci-fi interface featuring animated HUD elements, interactive calibration visuals, system metrics, and responsive layouts.

## ✨ Features

* Futuristic cybernetic UI/UX
* Responsive design for desktop, tablet, and mobile
* Animated neural-network HUD visualization
* Interactive mobile navigation
* Smooth scrolling navigation
* Scroll-based reveal animations
* Interactive calibration interface
* Animated system console
* Live system metrics
* Cybernetic integration timeline
* Futuristic CTA and footer sections
* Keyboard focus states
* `prefers-reduced-motion` accessibility support
* No external JavaScript frameworks or build tools required

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* SVG
* Google Fonts

  * Space Grotesk
  * JetBrains Mono

```bash

cd techfest-3d-interactive-website
```

Then open `index.html` in your browser.

## 🎨 Design Concept

The website follows a **cybernetic / futuristic technology** aesthetic using a graphite-based interface with copper and pulse-teal accents.

The concept explores the idea of:

> **Human cognition extended through synthetic intelligence.**

The interface is designed to resemble a futuristic neural-system control platform.

## 🧩 Main Sections

### Hero

Introduces the NEXUS-7 neural-synthetic platform with an animated node-network HUD.

### Core Systems

Presents the platform's major fictional subsystems through interactive cards.

### Interactive Interface

Displays a futuristic calibration dashboard with animated system parameters and a simulated boot console.

### Field Metrics

Shows system performance statistics.

### Integration Path

Presents the fictional journey from neurological baseline to full system integration.

### Final CTA

Provides a futuristic access/request interface to complete the landing-page experience.

## 📱 Responsive Design

The website is optimized for:

* Desktop
* Laptop
* Tablet
* Mobile

The navigation automatically changes to a mobile menu on smaller screens.
